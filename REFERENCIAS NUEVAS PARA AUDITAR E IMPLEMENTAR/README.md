# REFERENCIAS NUEVAS PARA AUDITAR E IMPLEMENTAR

Carpeta de recepción de documentos de mejora de RUBIK SOTA.

**Estado de los materiales:** PENDIENTES DE AUDITAR. La subida de un PDF no aprueba su contenido ni autoriza la implementación de sus propuestas.

## Cómo incorporar materiales
1. Subir aquí los PDF originales sin modificarlos, con nombres descriptivos.
2. Conservar autor, fecha, versión y fuente si están disponibles.
3. Para cada documento se elaborará posteriormente una ficha de auditoría: capacidades existentes que ya resuelven la propuesta, diferencias, riesgos, dependencias, presupuesto/alcance, licencias, QA, prioridad y decisión del propietario.
4. No duplicar motores ni crear tareas de desarrollo hasta una decisión y autorización explícitas.

## Estados documentales
- RECIBIDO: material guardado, sin examen.
- AUDITORIA_PENDIENTE: requiere cotejo con GitHub y documentos maestros.
- AUDITADO: evaluación reproducible con pruebas y SHA.
- PROPUESTO: opción recomendada, pendiente de decisión.
- APROBADO_PARA_PLANIFICAR: decisión expresa, **no** implementación automática.
- IMPLEMENTADO_VERIFICADO: solo con evidencia por SHA, QA y aceptación competente.

Esta rama es de **referencias y análisis**, separada del desarrollo. No hacer merge, Production, activar servicios de pago o publicar material de clientes sin autorización concreta.
