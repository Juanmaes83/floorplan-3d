# Rubik — Operations entrypoint

Para cualquier cuenta/agente que entre a trabajar en Rubik:

1. Leer `docs/product/current-status-2026-11-02.md`.
2. Leer `docs/ops/ACTIVE-WORKSTREAMS.md`.
3. Leer `docs/ops/MULTI-AGENT-OPERATING-PROTOCOL.md` antes de iniciar un workstream con escritura.
4. Verificar `master`, branch y remote HEAD reales.
5. Si se reanuda trabajo ajeno, usar `docs/ops/HANDOFF-TEMPLATE.md` y el handoff/run-state específico.

Principio:

> **El repo y los checkpoints remotos son la memoria compartida; los chats no lo son.**

No iniciar escritura en una branch/worktree que ya tenga owner activo sin coordinación explícita.
